# ✂️ Видеонарезчик — Telegram-бот + мини-апп

Присылаешь видео → выбираешь временной отрезок (в мини-аппе ползунками или вручную) →
бот режет его на части нужной длины, по желанию вставляет твой баннер посередине
на всю ширину кадра → присылает все части обратно.

Бонус: 🧠 «умная нарезка» — границы частей подгоняются под смены сцен (детектор scdet ffmpeg).

## Структура

```
videocut_bot/
├── bot.py            # бот (aiogram 3, polling) + запуск HTTP-сервера
├── processing.py     # ядро: probe / нарезка / баннер / детектор сцен
├── server.py         # aiohttp-сервер мини-аппа (видео по токену, Range-запросы)
├── webapp/index.html # мини-апп: плеер + ползунки отрезка + настройки
├── test_pipeline.py  # самотест пайплайна без Telegram
├── requirements.txt
├── .env.example
└── demo/             # пример части с баннером + кадр для проверки
```

## Запуск

1. **Создай бота**: в Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → получишь токен.

2. **Установи зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
   ffmpeg подтянется автоматически через `static-ffmpeg` (или используй системный).

3. **Настрой `.env`** (скопируй из `.env.example`):
   ```
   BOT_TOKEN=<токен от BotFather>
   WEBAPP_URL=<https-адрес мини-аппа, см. ниже>
   HTTP_PORT=8080
   ```

4. **Мини-аппу нужен публичный HTTPS-адрес** (требование Telegram).
   Для локального запуска проще всего ngrok:
   ```bash
   ngrok http 8080
   ```
   Скопируй выданный `https://....ngrok-free.app` в `WEBAPP_URL`.
   Без `WEBAPP_URL` бот работает, но только с ручным вводом времени.

5. **Старт**:
   ```bash
   python bot.py
   ```

## Использование

- `/start` — инструкция
- Пришли видео (до 20 МБ — лимит скачивания Bot API) **или ссылку на видео**
  (YouTube и ~1000 других сайтов через yt-dlp; до 2 ГБ, качество до 1080p)
- Кнопка **«✂️ Выбрать отрезок в мини-аппе»** → плеер, ползунки начала/конца,
  длина части, умная нарезка, баннер → **«Нарезать»**
- Или **«Ввести время вручную»** → `0:05-1:30` → выбор длины части
- `/banner` — загрузить баннер: **картинку (PNG/JPG) или видео/GIF**
  (встанет на всю ширину по центру каждой части; видео-баннер зацикливается)
- `/delbanner` — убрать баннер
- `/settings` — длина части по умолчанию, баннер вкл/выкл, умная нарезка
  и ⚡ быстрый режим (спрашивает только отрезок — остальное из настроек)
- `/cancel` — отмена

## Автоподдержка туннеля

`tunnel_watchdog.sh` держит HTTPS-туннель (localhost.run) живым: если он падает,
переподнимает его, обновляет `WEBAPP_URL` в `.env` и перезапускает бота.
Запуск: `./tunnel_watchdog.sh` (или `nohup ./tunnel_watchdog.sh > watchdog.log 2>&1 &`).

## Лимиты Telegram (важно)

- Скачивание файла ботом: **до 20 МБ** через обычный Bot API.
  Больше — нужен [локальный Bot API сервер](https://core.telegram.org/bots/api#using-a-local-bot-api-server).
- Отправка видео ботом: **до ~50 МБ** на файл. Если часть получилась больше,
  бот предупредит — возьми короче отрезок или меньше длину части.

## Тесты

```bash
python test_pipeline.py
```
Генерирует видео со сменами сцен и баннер, прогоняет нарезку (обычную, умную,
с баннером и без), проверяет длительности/разрешение/звук ffprobe'ом.
